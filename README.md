# RADD | رَدّ

## نظام لاستعادة فرص التواصل الأسري

هذه النسخة هي **MVP تفاعلي** يشرح بشكل مباشر كيف ينتقل التواصل من الطفل إلى الأب، وماذا يحدث عندما لا يستطيع الأب الرد فورًا.

### التدفق الأساسي

`الطفل يرسل فرصة → رَدّ يسلّمها للأب → الأب يختار الآن أو لاحقًا → تذكير → استعادة التفاعل → قياس النتيجة`

### كيف يعرف الأب بوجود التواصل؟

في النموذج الحالي:

1. يختار الطفل نوع التواصل.
2. يضغط **«أبلغ أبي واحفظ فرصة التواصل»**.
3. تظهر الفرصة فورًا في **صندوق الأب** مع تنبيه وعدّاد.
4. يستطيع الأب:
   - **أعود الآن**
   - **بعد 10 دقائق**
   - **بعد 20 دقيقة**
   - **عند انتهائي**
5. عند العودة يسجل النظام لحظة الاستعادة وزمنها.

### المزامنة في هذا الـMVP

لأن المشروع الحالي هو نموذج عرض يعمل بدون Backend، تتم المزامنة بين نافذتي المتصفح باستخدام:

- `localStorage`
- `BroadcastChannel`

وهذا يسمح بعرض دور الطفل ودور الأب كتجربة حية داخل المتصفح.

### الانتقال إلى نسخة حقيقية على هاتفين

في النسخة الإنتاجية يمكن استبدال طبقة المزامنة المحلية بـ:

`Firebase Firestore + Firebase Cloud Messaging (FCM)`

بحيث:

- جهاز الطفل ينشئ فرصة تواصل في Firestore.
- حساب الأب المرتبط بالأسرة يستقبل التغيير.
- FCM يرسل إشعار Push حقيقي.
- عند الاستعادة تسجل `returnedAt`.
- تُحسب مؤشرات الاستعادة من البيانات الفعلية.

### الخصوصية

RADD في تصميمه الحالي لا يحتاج إلى:

- تسجيل صوت دائم
- كاميرا
- مراقبة شاشة
- قراءة رسائل خاصة

التفاعل يبدأ بإدخال صريح من المستخدم.
