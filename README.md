# RADD | رَدّ

## نظام لاستعادة فرص التواصل الأسري

RADD هو نموذج أولي (MVP) يعالج لحظة بسيطة داخل الأسرة: عندما يحاول أحد أفراد الأسرة التواصل، لكن الطرف الآخر لا يستطيع الاستجابة في تلك اللحظة.

بدل أن تنتهي اللحظة بـ«بعد شوي»، يحافظ RADD على فرصة التواصل ويعيدها إلى الطرف المعني في وقت مناسب، ثم يسجل ما إذا تمت العودة والتفاعل فعليًا.

### الفكرة

**محاولة تواصل ← تعذر الرد ← حفظ فرصة التواصل ← تذكير مناسب ← العودة ← استعادة التفاعل ← علاقة أقوى**

> إذا لم تستطع أن تكون حاضرًا الآن… لا تجعل فرصة التواصل تختفي.

### ما يميّز RADD

RADD لا يركز فقط على تقليل وقت الشاشة أو منع استخدام الهاتف. نقطة التدخل الأساسية هي **ما بعد تعذر الاستجابة لتفاعل أسري محدد**.

يحفظ النظام فرصة التواصل، يحدد أولويتها، يختار وقتًا مناسبًا للعودة، ثم يتحقق من استعادة التفاعل.

### الخصوصية

النموذج لا يحتاج إلى ميكروفون دائم أو كاميرا أو مراقبة الشاشة أو قراءة محادثات خاصة. التفاعل يُسجّل بإدخال صريح من المستخدم.

### النموذج

الملف `index.html` يحتوي على Demo مستقل يعمل مباشرة في المتصفح للتجربة الأساسية.

## تشغيل محلي

افتح `index.html` مباشرة في المتصفح، أو شغّل:

```bash
python -m http.server 8080
```

ثم افتح http://localhost:8080
